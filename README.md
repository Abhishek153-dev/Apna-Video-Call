Apna Video Call 📹

A real-time full stack video conferencing and chat application built using React.js, Node.js, Express.js, Socket.io, and WebRTC.

🚀 Features
🔴 Real-time Video Calling
💬 Live Chat Messaging
🎤 Mute / Unmute Audio
📷 Turn Camera On / Off
👥 Multiple User Support
⚡ Fast Socket.io Communication
🌐 WebRTC Peer-to-Peer Connection
📱 Responsive UI Design
🔒 Secure Room-Based Calling

⚙️ Installation
1️⃣ Clone Repository
git clone https://github.com/your-username/apna-video-call.git
2️⃣ Install Backend Dependencies
cd Backend
npm install
3️⃣ Install Frontend Dependencies
cd ../Frontend
npm install
▶️ Run Project
Start Backend
cd Backend
npm start
Start Frontend
cd Frontend
npm start
🌐 Environment Variables

Create a .env file inside Backend folder:

PORT=5000
